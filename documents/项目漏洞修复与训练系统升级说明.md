# T1机器人足球项目 - 漏洞修复与训练系统升级

## 🔧 已修复的漏洞

### 1. **train.py 重构**
- **问题**: 原来的训练系统使用自定义Runner，无法直接使用AMP功能
- **解决**: 完全重构train.py，直接集成AMPOnPolicyRunner和OnPolicyRunner
- **优势**: 支持普通PPO和AMP训练模式自动切换

### 2. **set_seed函数缺失**
- **问题**: utils/utils.py缺少set_seed函数，导致无法设置随机种子
- **解决**: 添加了完整的set_seed函数，支持CPU和GPU的随机数生成器
- **功能**: 确保训练的可重复性

### 3. **AMP观察维度错误**
- **问题**: 专家数据生成器使用错误的观察维度（64维而不是37维）
- **解决**: 更新create_expert_data.py，使用正确的AMP观察维度
- **影响**: 确保专家数据与环境兼容

### 4. **terminal_amp_states 边界条件**
- **问题**: 用户简化代码时可能导致空索引错误
- **解决**: 添加边界条件检查，防止env_ids为空时的错误
- **安全**: 提高代码稳定性

### 5. **配置文件路径问题**
- **问题**: AMP配置文件中使用空的amp_motion_files列表
- **解决**: 设置默认路径为"data/expert_kick_data.yaml"
- **便利**: 简化用户配置过程

## 📋 使用指南

### 快速开始

#### 1. **训练模型**
```bash
# 方式1: 使用快速启动脚本（推荐）
python run_train.py

# 方式2: 直接命令行训练
python train.py --task kick_2D --num_envs 2048         # PPO训练
python train.py --task kick_2D --use_amp --num_envs 2048  # AMP训练
```

#### 2. **演示模型**
```bash
# 自动加载最新模型演示
python play.py

# 指定模型文件演示
python play.py --load_run path/to/model.pt

# 多环境演示
python play.py --num_envs 4

# 无头模式演示
python play.py --headless
```

#### 3. **生成专家数据**（AMP训练必需）
```bash
python create_expert_data.py --method manual --output data/expert_kick_data.yaml
```

#### 4. **监控训练**
```bash
tensorboard --logdir=logs
```

### 训练模式选择

| 模式 | 命令 | 特点 |
|------|------|------|
| **普通PPO** | `python train.py --task kick_2D` | 快速收敛，适合初学者 |
| **AMP训练** | `python train.py --task kick_2D --use_amp` | 自然运动，需要专家数据 |
| **继续训练** | `python train.py --checkpoint -1` | 从最新检查点恢复 |

### 参数说明

| 参数 | 默认值 | 说明 |
|------|--------|------|
| `--task` | kick_2D | 任务名称 |
| `--num_envs` | 配置文件 | 并行环境数量 |
| `--max_iterations` | 30000 | 最大训练迭代次数 |
| `--use_amp` | False | 是否使用AMP训练 |
| `--headless` | False | 无头模式运行 |
| `--seed` | 42 | 随机种子 |
