# T1机器人足球训练系统 - 使用说明

## 🚀 快速开始

### 方式1：交互式菜单（推荐）
```bash
python run_train.py
```

### 方式2：直接命令行
```bash
# PPO训练
python train.py --task kick_2D

# AMP训练（需要先生成专家数据）
python train.py --task kick_2D --use_amp

# 模型演示
python play.py

# 生成专家数据
python create_expert_data.py --method manual --output data/expert_kick_data.yaml
```

## 📋 详细功能

### 1. 训练模型

#### PPO训练（推荐新手）
```bash
python train.py --task kick_2D --num_envs 2048 --max_iterations 30000
```
- 收敛快，易于调试
- 适合快速验证环境和奖励设计

#### AMP训练（高质量运动）
```bash
# 先生成专家数据
python create_expert_data.py --method manual --output data/expert_kick_data.yaml

# 开始AMP训练
python train.py --task kick_2D --use_amp --num_envs 2048 --max_iterations 50000
```
- 学习自然流畅的运动
- 训练时间长，但效果更好

### 2. 演示模型

#### 基础演示
```bash
# 自动加载最新模型
python play.py

# 指定特定模型
python play.py --load_run logs/model_10000.pt

# 多环境演示
python play.py --num_envs 4

# 无头模式运行
python play.py --headless
```

### 3. 专家数据生成

#### 手动预设动作
```bash
python create_expert_data.py --method manual --output data/expert_kick_data.yaml
```

#### 从训练模型提取
```bash
python create_expert_data.py --method model --model path/to/model.pt --output data/expert_data.yaml
```

## ⚙️ 配置说明

### 配置文件位置
- **统一配置**: `envs/kick_2D.yaml`
- 包含PPO和AMP的所有配置选项

### 关键配置项

#### 启用/禁用AMP
```yaml
# 在命令行使用 --use_amp 时，这些会自动设置：
env:
  reference_state_initialization: true    # AMP模式
  amp_motion_files: ["data/expert_kick_data.yaml"]

runner:
  algorithm_class_name: "AMPPPO"          # AMP算法

algorithm:
  class_name: "AMPPPO"                    # AMP算法
```

#### 训练参数调整
```yaml
basic:
  max_iterations: 30000      # PPO: 30000, AMP: 50000
  num_envs: 4096            # 根据GPU内存调整

runner:
  save_interval: 1000       # 模型保存频率
  amp_reward_coef: 2.0      # AMP奖励权重
```

## 📊 性能参考

### 硬件需求
- **最低**: GTX 1060 6GB, 8GB RAM
- **推荐**: RTX 3080 12GB, 32GB RAM  
- **最佳**: RTX 4090 24GB, 64GB RAM

### 训练时间
| 模式 | 环境数 | 迭代数 | 预计时间 |
|------|--------|--------|----------|
| PPO  | 2048   | 30,000 | 3-5小时  |
| AMP  | 2048   | 50,000 | 8-12小时 |

### 内存使用
- 2048环境: ~8GB GPU内存
- 4096环境: ~12GB GPU内存

## 🔧 常见问题

### Q: 训练中断如何恢复？
```bash
python train.py --task kick_2D --checkpoint -1  # 最新检查点
python train.py --task kick_2D --checkpoint logs/model_5000.pt  # 指定检查点
```

### Q: 如何调整训练速度？
```bash
# 减少环境数量（降低GPU占用）
python train.py --task kick_2D --num_envs 1024

# 增加环境数量（提高训练效率）  
python train.py --task kick_2D --num_envs 4096
```

### Q: AMP训练不收敛？
1. 检查专家数据质量
2. 调整 `amp_reward_coef` (默认2.0)
3. 调整 `amp_task_reward_lerp` (默认0.3)

### Q: 演示时模型表现不佳？
1. 确保使用相同的环境配置
2. 检查模型是否完全加载：`python play.py --load_run path/to/model.pt`
3. 尝试不同的检查点

## 📈 监控训练

### TensorBoard
```bash
tensorboard --logdir=logs
# 在浏览器打开: http://localhost:6006
```

### 重要指标
- **Episode Reward**: 总奖励，越高越好
- **Success Rate**: 成功率，踢球任务的成功比例
- **Policy Loss**: 策略损失，应该稳定下降
- **AMP Reward**: （AMP模式）对抗奖励

## 🎯 训练技巧

1. **从PPO开始**: 先用PPO验证环境设置正确
2. **数据质量**: AMP训练的关键是高质量专家数据
3. **超参数调节**: 根据任务特点调整奖励权重
4. **渐进训练**: 从简单任务开始，逐步增加难度
5. **定期评估**: 使用演示功能定期检查训练效果

## 📝 日志位置

- **训练日志**: `logs/kick_2D_ppo/` 或 `logs/kick_2D_amp/`
- **模型文件**: `logs/*/model_*.pt`
- **配置文件**: `logs/*/config.yaml`
- **TensorBoard**: `logs/*/summaries/`
